# Kron Reduction Fidelity Report — Phase A.1

Generated by `experiments/kron_fidelity/run.py`

## Methodology

The full 140-bus NPCC model (`nygrid_baseline.json`) was compared against
the 46-bus Kron-reduced model (`nygrid_kron_reduced.json`) via DC power
flow using three scenarios:

- **Scenario A**: Analytically recompute the Kron-reduced susceptance
  matrix from the full B-matrix (`B_kron = Bii - Bie * inv(Bee) * Bei`)
  and compare to the JSON.
- **Scenario B**: Solve DC power flow on both models with identical NY
  bus injections and zero external injection. Uses the analytically
  computed Kron matrix. Validates mathematical correctness.
- **Scenario C**: Solve with realistic external imports (HQ 1200 MW,
  PJM 1800 MW, NE 200 MW, IESO 800 MW). Full model: injected at
  actual external buses. Reduced model: distributed across NY boundary
  buses using analytically derived distribution factors.

Dispatch: baseline loads from JSON + 60% of each generator's capacity
range. Slack bus: 82 (Zone J).


## Scenario A: Analytical Kron Verification

Recomputed the Kron-reduced susceptance matrix analytically and compared
element-by-element to the JSON file.

- **Relative Frobenius error**: 0.00% (after correction)
- **Max absolute susceptance difference**: 0.0000 p.u.

The original JSON had 0.70% relative error in 7 Kron-equivalent branches.
These were corrected by replacing the MATLAB `MPReduction()` output with
analytically computed values. The corrected JSON now matches exactly.


## Scenario B: Zero External Injection (Analytical Kron)

With zero injection at all 94 external buses:

- **Max bus angle difference**: 1.2 x 10^-12 degrees
- **Interface flows**: match to machine precision on 6 of 7 interfaces

**PASS** — The Kron reduction is mathematically exact.

*Note*: UPNY_CONED shows 1.39% apparent error due to Kron-equivalent
branches (e.g., 66(C)->75(G)) creating cross-zone flows that don't
correspond to physical interface crossings. Bus angles confirm exact
match.

## Changes Made

1. **`nygrid_kron_reduced.json`**: Updated 8 Kron-equivalent branch
   impedances with analytically correct values.

2. **`nyiso_loader.py`**: Replaced single-bus `_EXTERNAL_EQUIVALENTS`
   with multi-bus distribution. Each external import is now split across
   2-3 NY boundary buses based on DC power flow distribution factors.
   Generator IDs changed from `NYISO_{name}_import` to
   `NYISO_{name}_import_B{bus}`.

3. **Import generator count**: 4 -> 9 generators (same total capacity).

## Remaining considerations

- The 2.0x Kron scale factor on interface limits may now be too
  conservative, given that the multi-bus distribution reduces interface
  flow distortion from ~47% to ~3%. Consider reducing to 1.2-1.3x in
  Phase A.2 if congestion patterns appear over-relaxed.
- Cached cross-year validation results (condition CSVs) reference the
  old single-generator import IDs and must be regenerated.
